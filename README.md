# grid_arena_game

Grid-based real-time battle arena prototype built with Godot 4.7 (GDScript).

- Open `project.godot` in Godot 4.7+ and press F5 to play the battle scene.
- Project conventions and game vocabulary: [CLAUDE.md](CLAUDE.md)
- Testing strategy and automation: [docs/TESTING_PLAN.md](docs/TESTING_PLAN.md)

```bash
tools/run_tests.sh                          # run the headless test suite
git config core.hooksPath tools/git-hooks   # run tests before every commit
```
